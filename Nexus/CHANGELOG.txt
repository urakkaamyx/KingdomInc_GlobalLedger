0.1.9
- Added a dedicated "Rolling Avg" toggle button directly on the top-right header
  bar beside Basic | Adv so you can toggle rolling averages on and off without
  needing to open the Mod Config menu. The button turns Gold when active.
- Fixed Basic mode displaying unlocked currencies and items with 0.00/{time} when
  they have not had any activity in the current window. Unearned currencies and
  unproduced items are now cleanly hidden from Basic mode unless Show All is
  toggled on.

0.1.8
- Added Mod Config menu integration via Foundation ModConfig.
- Added "Rolling average" toggle in the Mod Config menu:
  "(Checking this box enabled Rolling average .. makes the calulations less jumpy but not as accurate realtime)".
- Added "Entry Count" slider in the Mod Config menu (range 2 to 30, default 3):
  When enabled, rate calculations are averaged over the chosen number of entries
  based on the selected time unit (e.g., 3 entries over 3 seconds for /sec,
  or 3 entries over 3 minutes for /min and /hour).

0.1.7
- Fixed an issue where opening Global Ledger on the Tech Tree screen caused the
  ledger to flash and disappear immediately.
- Made Global Ledger remain open and fully interactive while viewing the Tech Tree.
- Clicking View on a building or container while on the Tech Tree screen exits the
  Tech Tree and focuses the target in the workspace without closing the ledger.

0.1.6
- Added Basic / Adv mode toggle buttons in the top-right corner.
  - Basic mode displays a streamlined overview of Currency Net Collection and
    Item Net Production ([Icon] [Name] +/-XXX[icon] / {sec|min|hour}), with
    items sorted by Tier -> A-Z.
  - Adv mode retains the full hierarchical breakdown (Currency/Item > Container
    > Building > Operating Costs) and defaults to everything collapsed.
- Added [sec | min | hour] rate scaling toggle buttons in the header bar
  (defaulting to min) so you can quickly inspect rates per second, minute,
  or hour across all rows.

0.1.5
- Kept the Global Ledger dropdown open when clicking a View button so you can
  center and highlight buildings or containers without reopening the ledger.
- Disambiguated duplicate container names with stable _# suffixes (_1, _2, etc.)
  based on workspace coordinates to prevent them from jumping around.

0.1.4
- Fixed Medals income tracking: attributed war combat medal earnings from
  WarProgress.UpdateWar directly to active workspace War Effort buildings.
- Grouped fallback war combat medal earnings without workspace War Effort
  buildings under a dedicated War Progress category.

0.1.2
- Added the full Production tab matching the Currencies hierarchy: Item root
  (<Item> - Net Production in /min) > Container > Building > Operating Costs
  (icon-only rows for consumed input items in /min and spent currencies).
- Sorted unlocked items on the Production tab by Tier (Tier 1-12) then A-Z,
  hiding zero-activity items by default with a Show All toggle in the header.
- Added a Collapse All button in the header bar to collapse all open roots,
  containers, buildings, and operating cost groups on the active tab.
- Added a dedicated right-aligned View button on live container and building
  rows to jump to, center, and highlight the target without row clicks moving
  the camera.
- Updated container rows to show [ContainerIcon] | [ProductionIcon]
  [ContainerName] using the native green container sprite alongside the
  container's sticker or building production icon.
- Stripped TextMeshPro rich-text tags (such as <size=...>) from container and
  workspace labels.
