0.1.11
- Fixed Basic mode showing unlocked items with 0.00/{time} when they have never
  been produced in the session.
- Implemented exact activity lifecycle filtering in Basic mode:
  * Items and non-gold currencies that have never been produced or earned are hidden.
  * Items and currencies actively being produced/earned show their live rates.
  * Items and currencies whose production drops to 0 remain visible displaying
    0.00/{time} for exactly one rolling minute (60 seconds) so halted production
    is clearly visible.
  * After one rolling minute with no production, they cleanly drop off.
  * Toggling "Show All" lists all unlocked items and currencies as before.

0.1.10
- Added a dedicated "Rolling Avg" toggle button directly on the top-right header
  bar beside Basic | Adv so you can toggle rolling averages on and off without
  needing to open the Mod Config menu. The button turns Gold when active.
- Refined Basic mode zero-rate behavior: when production or earnings halt and
  rates drop to 0, rows do not immediately drop off. Instead, they remain visible
  at 0.00/{time} across the active window duration so you can clearly see that
  production has stopped. Once inactive for the full window, they cleanly drop off.
  Unearned currencies and unproduced items that were never made remain hidden
  unless Show All is clicked.

0.1.9
- Initial Basic mode zero-rate filtering.

0.1.8
- Added Mod Config menu integration via Foundation ModConfig.
- Added "Rolling average" toggle in the Mod Config menu:
  "(Checking this box enabled Rolling average .. makes the calulations less jumpy but not as accurate realtime)".
- Added "Entry Count" slider in the Mod Config menu (range 2 to 30, default 3):
  When enabled, rate calculations are averaged over the chosen number of entries
  based on the selected time unit (e.g., 3 entries over 3 seconds for /sec,
  or 3 entries over 3 minutes for /min and /hour).
